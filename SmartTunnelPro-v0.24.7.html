لاگ

امنیت این نسخه

Smart Tunnel v0.9.0 پروفایل‌ها و Subscriptionهای داخل APK در storage محلی با AES-256-GCM رمز می‌شوند؛ کلید مشتق‌شده از secret داخل Android Keystore است. Export قابل حمل با PBKDF2-HMAC-SHA256 + AES-256-GCM و password محافظت می‌شود. همچنین Split Tunnel از addDisallowedApplication و FD blocking از setBlocking(true) استفاده می‌کند. این فایل HTML برای UI و مدیریت پروفایل‌هاست؛ Config Builder خروجی JSON استاندارد sing-box می‌سازد؛ Native Bridge در APK وظیفهٔ ارتباط با Android و VPNService را دارد.

Acode

برای اجرای همین فایل، آن را در Acode باز کن و Preview بزن. نیاز به KSWEB، PHP یا Termux ندارد. در این حالت فقط امکانات مرورگر فعال‌اند.

VPN واقعی

Android فقط با VpnService می‌تواند یک VPN سراسری بسازد و کاربر باید مجوز سیستم را تأیید کند. موتور sing-box نیز روی Android در حالت TUN از همین زیرساخت استفاده می‌کند. بنابراین نسخهٔ Native را باید به‌صورت APK ساخت.

پایداری

URLTest/failover می‌تواند انتخاب خروجی را بهتر کند، ولی پایداری به سلامت سرورها، مسیر اپراتور، DNS، تغییر شبکه و سیاست‌های مقصد بستگی دارد. هیچ app یا configی تضمین دائمی برای ایران نمی‌دهد.

ساخت زیرساخت

از همین مدل می‌توان بعداً سرورهای شخصی، API اشتراک، health-check، انقضا، سهمیه، پنل مدیریت، مانیتورینگ و تولید خودکار config را اضافه کرد. «Signal» به معنای آنتن/شبکهٔ رادیویی چیزی نیست که این نرم‌افزار بسازد؛ اگر منظورت سیگنال دسترسی شبکه است، کیفیت آن به خود شبکه و مسیر بالادستی وابسته است.
